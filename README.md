# tahto-app/.github

Organisation-wide defaults for every Tahto repository: pull request and
issue templates (`.github/`), the security policy (`SECURITY.md`) and
contribution rules (`CONTRIBUTING.md`). A repository that ships its own copy
of a file overrides the default here.

This repository is public because GitHub only applies default community
health files from a public `.github` repository. It contains no code and no
configuration.

Security reports: see `SECURITY.md`.
