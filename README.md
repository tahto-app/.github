# tahto-app/.github

Org-wide defaults for every `tahto-app` repository: pull request template,
issue templates, security policy and contribution rules. A repository that
ships its own copy of a file overrides the default here.

Repositories:

| Repo | Purpose |
| --- | --- |
| `tahto-mobile` | Expo / React Native app |
| `tahto-api` | Express backend (auth, Stripe, Alpaca broker, KYC) — SOC 2 in-scope system |
| `tahto-website` | Marketing site (Vite + React, Netlify) |
| `tahto-docs` | Engineering and product documentation, copy manifests, Figma exports |
| `tahto-infra` | Deploy configuration, environment schema, runbooks |
| `tahto-compliance` | SOC 2 policies, risk register, vendor inventory, access reviews |
